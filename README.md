# Spare

A weekly screen-time ledger. Set a daily budget, log what you actually used, and watch the remainder add up.

## Features

- Daily budget, down to the minute
- Type or paste times (`1h 43m`, `1:43`, `103`, `4 ure 12 minut`)
- Week view with time spared vs over budget
- Last eight weeks
- Data stays on the device (`localStorage`)

## Run locally

```bash
npm install
npm run dev
```

Then open the URL Vite prints (port 8080).

## Stack

TanStack Start, React, Tailwind CSS v4, Zustand, date-fns.
